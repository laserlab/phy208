## History facts on the "Why Poincaré did not write a matrix" slide

Not images, but sourced claims, listed here so the next session can check them:

| Claim | Source |
|---|---|
| Sylvester coins "matrix", 1850 | *Phil. Mag.* 37:363–370, "an oblong arrangement of terms" from which determinants are generated |
| Cayley, *A Memoir on the Theory of Matrices*, 1858 | *Phil. Trans. R. Soc.* 148:17–37; Higham, *Linear Algebra Appl.* 428:39–43 (2008) calls it "the first paper on matrix algebra" |
| Poincaré cites Sylvester's matrices, 1884 | "Sur les nombres complexes": *"Les remarquables travaux de M. Sylvester sur les matrices…"* — via Brechenmacher, [arXiv:1210.3945](https://arxiv.org/pdf/1210.3945) |
| Minkowski writes $x = Ax'$, $f' = A^{-1}fA$, 1908 | *Grundgleichungen*, Nachr. Ges. Wiss. Göttingen 53–111 — via Damour, [arXiv:0807.1300](https://arxiv.org/pdf/0807.1300). **Not** *Raum und Zeit*, which is geometric |
| Determinants predate matrices | Seki 1683, Leibniz 1693, Cramer 1750, Gauss 1801, Cauchy 1812 — [MacTutor](https://mathshistory.st-andrews.ac.uk/HistTopics/Matrices_and_determinants/) |
| Born recognised Heisenberg's rule as matrix multiplication, 1925 | Aitchison et al., [quant-ph/0404009](https://arxiv.org/pdf/quant-ph/0404009) |

Traps deliberately avoided on the slide: *"Minkowski used no matrices"* (false
outside *Raum und Zeit*), *"Poincaré didn't know about matrices"* (he cited
them in 1884), *"Cayley proved Cayley–Hamilton"* (stated generally, verified
only small cases), and *"Heisenberg invented matrix mechanics"* (Born and
Jordan made it matrix mechanics).
