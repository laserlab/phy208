## Embedded tools

`interval.html` is embedded as a full-slide iframe and is the lecture's
demonstration. It is a copy of `Lectures/_shared/tools/interval.html`,
original work, CC BY-SA 4.0.

Students run it themselves, one instance per pair, seeded by group name. The
seeding is a deterministic hash of the name, so a group's events are
reproducible at home and regenerable for grading. See the comments in the tool
for the exact function.
